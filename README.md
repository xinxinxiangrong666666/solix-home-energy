# 每度有据｜SOLIX 风格 3D 家庭能源官网原型

这是 Anker SOLIX Home Energy Studio 独立产品官网原型。页面参考 Anker SOLIX 官方产品页的内容层级、产品摄影、黑白高对比、橙色行动点和“先用户结果、后技术与安全证明”的表达方式，但不复制官方页面源码。

## 主要功能

- SOLIX 风格产品官网首屏与完整长页面；
- Three.js 室内家庭 + 室外车位一体化能源 3D 孪生场景；
- 3D 电力链路补齐屋顶微型逆变器、家庭配电箱、智能电表与 CT、可选智能插座；可聚焦查看三个节点。Solarbank Max AC 按交流耦合接线展示，电表屏幕只显示本地模拟电网功率；
- 能源实验室采用上下两层布局：3D 与实时控制在上，决策链、动作解释和证据助手横向铺在下方；窄屏改为单列，避免右侧长面板与左侧大片留白；
- CC BY 4.0 授权的 Tesla Model 3 PBR 模型与 SOLIX V1 风格车充；
- 晴朗、多云、雨天、雷暴、降雪、夜间六种可切换天气/时间场景；
- 雷暴与降雪会联动光伏预测、备电目标、车辆充电和 AI 解释；
- 真实比例的织物沙发、橡木皮椅、石材茶几、三脚落地灯、盆栽、冰箱、洗衣机、车辆和动态添加设备可拖动布置；挂墙电视沿墙滑动，固定媒体柜与屋顶光伏不可拖动；
- Solarbank Max AC 按官方公布的 `670 × 356 × 325 mm` 比例概念建模，产品特写视角单独近距离展示；它不是官方 CAD；
- 窗外与电视换成项目生成的照片级贴图，地板使用 Poly Haven CC0 PBR 木材，光伏由屋顶结构与支架实际支撑；
- 选中物体后可按 15° 旋转，布局在浏览器本地保存；
- 家具边界与碰撞检测，阻止穿墙、重叠和穿入产品区；
- 空白区域拖动旋转、滚轮缩放、能源全景/室内/车充/产品/俯视视角与布局重置；
- 光伏、电池、家庭负荷、电网实时功率模拟；
- 自由添加、移除、启停和调整家庭设备；
- 智能优化、自发自用、备电优先和手动控制四种策略；
- 7 kWh 模拟电池 SOC 动态变化；
- 浏览器端 6 小时 / 24 时隙 LP 演示：电池与车充共同取本格方案，含演示用 €0.02/kWh 循环成本假设；团队正式目标为 24 小时 / 三站，尚待官方环境验证；
- “为什么不多充？”将同一组模拟输入加约束重解，并比较完整窗口的含循环成本目标值；到达功率上限或无可行解时直接说明，不拼造差额；
- 默认本地的证据助手：每次 LP 求解记录输入快照、首格动作、目标值与显式规则，当前标签页环形保留最近 96 条；支持充放原因、额外充电、保持待机等追问，并能点开引用的原始 JSON。用户了解发送范围后可主动开启云端文字解释；两种模式都没有设备控制权限；
- 三站合成情景预览：共享同一条模拟电价，各站独立光伏、负荷与 SOC；时间线仅展示当前网页真实的 6 小时 / 24 时隙计划，不冒充正式三站成绩；
- 决赛目标控制路径、数据保存/访问边界、未验证的官方结算位置、失效情景和下一代电池数据建议；这些说明不替代真实 HA 接入与现场演示；
- 最近 120 分钟光伏/负荷曲线；
- 决策解释与不影响设备的影子反事实；
- “感知→预测→优化→安全→解释”展示为工作原理，不冒充实时处理进度；网页只实现本地模拟，不包含现场 HA 写入。可选云端解释经服务端代理接入，仅负责文字；
- 中文 / English 全页切换；
- 配置本地保存和 JSON 导出；
- 桌面、平板和移动端响应式布局；
- WebGL/Three.js 加载失败时的静态降级画面。

## 运行方式

由于 Three.js 使用 ES Module，请通过本地 HTTP 服务打开，不建议直接双击 `index.html`。核心 Three.js 文件已保存在 `vendor/`，无需 CDN：

```powershell
cd D:\Codex\BOSS\安克黑客松\SOLIX_家庭能源官网_3D
python -m http.server 4173
```

浏览器访问：

```text
http://127.0.0.1:4173/
```

云端文字解释可选：配置服务端 `ARK_API_KEY` 或 `LLM_API_KEY` 后，改用 `python serve.py 4173` 启动。本地静态服务仍提供完整的模拟与本地解释；云端开关在没有可用代理时提示不可用。代理默认仅监听 `127.0.0.1`。

- `energy-evidence.test.js`：证据字段与 LP 输出一致、可按 JSON 输入重放、影子结果可引用、96 条环形边界的 Node 测试；
- `scene-realistic.js`：官方产品外形重建、真实 PBR 家具、HDR 环境光、相机控制、家具拖拽与碰撞检测；
- `assets/hero-solix-max-v2.png`：首屏概念合成图；
- `assets/night-solix-max-v2.png`：结尾与 3D 降级概念图；
- `ATTRIBUTIONS.md`：产品参考与第三方 3D 资产许可/署名。

## 数据与品牌边界

- 页面为交互产品原型，不是已上线的 Anker SOLIX 商业服务；
- 所有功率、价格、SOC、成本变化与解释均为本地模拟；
- 收益页的模拟 `R = 全量购电基准 − 买电支出 + 卖电收入`，以本页功率与同一条合成买卖电价逐段积分；仅切换到会重置时钟的非夜间新天气时清空账本，夜间切换和重复选择当前天气都保留累计，刷新页面归零。负价买电可形成负支出。此 `R` 不是官方同名字段或实际账单；`R_settled` 在无官方结算回执时始终显示“待官方结算”，不从 `R` 猜测；
- 不展示或承诺未经官方环境验证的收益成绩；
- 页面没有接入真实设备、真实 Home Assistant 或外部能源系统；
- 电表/CT、微型逆变器、配电箱和智能插座均为依据示意图重建的概念场景模型；智能插座没有接入逐设备测量或控制。Solarbank Max AC 的光伏经既有逆变器并入家庭交流侧，不表示光伏 DC 直接接入电池；
- 证据日志仅在当前标签页内存保留最近 96 条，刷新清空；设备与家具偏好保存在浏览器 localStorage。正式 EC2 环境的日志保留期与访问权限须现场另行确认；
- 站点 2/3 使用合成光伏、负荷与 SOC，电价与站点 1 共享；不是官方三站的实际数据或 `saving_settled_percent`；
- Solarbank 与 V1 车充为依据公开产品图和尺寸制作的程序化场景模型，不冒充官方 CAD；车辆使用单独署名的 CC BY 4.0 第三方模型。

## 进入正式演示前仍需完成

- 在官方 EC2/HA 环境核验三个实体后缀、`third_party_control` 切换、`power_control` 下发及逐站功率读回；此网站不能替代现场闭环。
- 用官方三站合并 `saving_settled_percent` 与设备原生自发自用基线形成真实对照，替换网站目前的“待官方结算”说明；不得使用浏览器模拟目标值冒充成绩。
- 明确正式环境日志保留期和访问权限，准备故障时可播放的备用演示视频；网站的本地证据日志只保留当前标签页最近 96 条，刷新即清空。
- 云端文字解释需用户主动开启，并由 `serve.py` 的 `/api/health` 确认本地代理已配置；没有可用代理时回到本地解释。代理使用服务器上的 `ARK_API_KEY` 或 `LLM_API_KEY`，不要把凭证放进静态网页。
